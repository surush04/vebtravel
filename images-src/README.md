# Original photographs

Put M-SAYYOD's original photos here, named after the photo slot they fill, then run `npm run images`.

| Slot | Used for |
| --- | --- |
| `hero-markhor` | Homepage hero (Markhor in Darvoz landscape) + Open Graph image |
| `about-main`, `about-detail` | About section (large + inset image), About page hero |
| `activity-hunting`, `activity-expeditions`, `activity-ecotourism`, `activity-photography`, `activity-conservation` | Activity cards and Activities page |
| `dest-zighar`, `dest-darvoz`, `dest-landscapes`, `dest-habitats` | Destinations showcase |
| `conservation-markhor`, `conservation-detail` | Conservation section |
| `contact-landscape` | Footer call-to-action and Contact page hero |
| `gallery-01` … `gallery-16` | Gallery (portrait: 01, 04, 06, 08, 13, 14, 15 · landscape: 02, 03, 05, 10, 11 · square: 07, 09, 12, 16) |

Use authentic photography that M-SAYYOD owns or has a licence for. After adding photos, update their alt text in `public/i18n/*.json` → `media`.
